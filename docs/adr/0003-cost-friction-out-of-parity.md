# 资金费/真实滑点/部分成交视为奇偶性之外的执行摩擦

加密 perp 的资金费、真实滑点、部分成交**不回填进回测**；`model_core/backtest.py` 保持理想化的固定 0.03% 成本与全额成交假设。这些差异只在实盘报表里披露。

## 为什么

用户明确选择“奇偶性 = 逻辑层一致，不管成本”。资金费/滑点是**成本现实**，不是策略逻辑；把它们挡在奇偶性之外，可以让 `compute_target_positions` + 逐 bar 再平衡这条主线在回测和实盘间字面一致，而不必为加资金费去重训所有现有策略（现有 `best_*.json` 是在忽略资金的 reward 下选出来的）。

## 代价 / 后果

- 实盘会**系统性跑输回测**，缺口 = 累计资金费 + 超额滑点 + 未成交漂移；高换手或长期持仓的策略缺口最大。这是已知且被接受的。
- 因此评估策略优劣时不能只看回测分；实盘报表必须独立披露资金费占比、滑点、未成交率，供后续判断某策略是否“只在无成本世界好看”。
- 若将来发现资金费系统性吃掉某类策略的 alpha，可再以 ADR 形式回填资金费到回测，并重训——本 ADR 不阻止那个决定，只是明确 v1 不做。

## 放弃的方案

- 只回填资金费：资金费是连续持仓的主要隐性成本，方向×费率×名义可从交易所历史费率还原。更诚实，但改动回测成本项即改变 reward，现有策略需重评。
- 全量回填（资金费 + 真实 taker 费率 + 成交量相关滑点）：最诚实，工作量大，且重训后现有策略可能整体洗牌。
