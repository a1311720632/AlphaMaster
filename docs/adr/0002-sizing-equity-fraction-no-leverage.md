# 加密自动驾驶的仓位规模：权益分数、≤1x、不借钱

加密永续合约的名义价值映射为 `notional = tanh(factor) · 账户权益`，v1 不开杠杆（持仓名义始终 ≤ 权益）。

## 为什么

这是唯一能让实盘盈亏方程 `pnl ≈ position · target_ret − cost` 与回测（`model_core/backtest.py:429`，position 为单位名义）**字面对齐**的映射。任何杠杆因子 L 都会让实盘收益放大 L 倍，迫使回测同步改造、奇偶性变成"形状对齐"而非字面对齐。

## 代价 / 后果

- 加密 perp 是为杠杆设计的产品，**主动放弃杠杆**会显得反常——这是有意为之的安全默认值，不是技术限制。需要更高资金利用率时，再以"显式杠杆因子"的形式引入，并同步改回测。
- 满仓（|tanh|≈1）= 100% 权益作名义，保证金占用 = 名义 / 杠杆，1x 下即全款；这对小账户意味着可交易标的最小名义限制会更早触发。
- 跨标的可比性靠权益分数天然成立，无需 ATR 波动率目标——这与 MT5 路径的 `_calc_lot`（`runner.py:743-785`）是两套标度，自动驾驶不复用它。

## 放弃的方案

- 固定杠杆上限 × tanh：常见，但破坏绝对收益奇偶性，需要回测同步建模杠杆。
- ATR 波动率目标：复用 MT5 逻辑，但与回测"单位名义"完全是两套标度，且引入 ATR 估计误差，奇偶性最难定义。
